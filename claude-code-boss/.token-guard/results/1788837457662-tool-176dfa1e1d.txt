Passthrough/sticky na rota Anthropic preserva a cobrança da assinatura;\n> a rota BYOK e o fallback NVIDIA cobram o endpoint; uma `ANTHROPIC_API_KEY` no\n> ambiente vira API pay-as-you-go.
