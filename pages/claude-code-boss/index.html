plugin para Claude Code Desktop

O Claude Code que
não esquece — e melhora a cada sessão.

O claude-code-boss dá ao seu Claude Code uma memória semântica local, executa comandos de forma curada (sem poluir contexto) e transforma erros e padrões em lições reusáveis — automaticamente, sem você configurar nada.

01

O que ele faz por você

Três pilares, sem nada técnico para configurar.

🧠

Memória que funciona

O Claude lembra do que você já fez, aprendeu e errou — entre uma sessão e outra, entre projetos e máquinas.

  • Busca semântica em linguagem natural
  • Base de conhecimento local e offline
  • Memória por projeto, sem confusão entre os avanços de workspace
🛡️

Curação inteligente

Comandos e saídas são filtrados na hora — o contexto do Claude fica limpo e focado no que importa.

  • Comandos longos e ruidosos são encurtados
  • Hooks leves, sem atrapalhar o fluxo
  • Nada bloqueia seu trabalho
📈

Aprendizado contínuo

Erros e padrões viram lições reusáveis. Cada correção sua ensina o Claude a não repetir.

  • Erros e correções viram lições
  • Padrões de código reaproveitados
  • Tudo automático, sem relatórios

O que você ganha

Resultados que se somam a cada dia de uso.

menos repetição

Seu Claude não re-aprende do zero.

contexto limpo

Sessões mais focadas.

escala com o tempo

Instale em 2 minutos

Funciona com Claude Code Desktop, Node.js 22.13+ e mais nada. Todo o resto vem pronto — sem chave de API, sem servidor, sem conta.

  1. Adicione o marketplace  AllanSantos-DV/claude-code-plugins
  2. Instale o plugin  um comando, pronto
  3. Comece a usar — a memória indexa sozinha em segundo plano
