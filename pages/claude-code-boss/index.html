o loop · o que acontece a cada turno

Você escreve o prompt Pergunta, pedido ou correção. O hook do turno é um processo só, não um por detector.
entrada
O Brain recupera o que é relevante O prompt é embedado no daemon local (quente, na casa dos milissegundos) e as lições acima do gate entram como um bloco [BRAIN].
Comandos ruidosos são curados na hora A guarda de curadoria encurta ou redireciona saídas gigantes; um comando cuja assinatura já falhou várias vezes volta com a causa registrada, em vez de falhar de novo.
Sua correção vira lição durável O agente chama capture_lesson ainda no loop, com contexto completo: dedup e merge inline somam recorrência em vez de duplicar. Nada de reler transcript nem subagente caro.

Seu endpoint, no protocolo que ele fala.

01 · configure

Dashboard ou ambiente

Abra /dashboard → Router para escolher protocolo, URLs e headers. Em automação, use ROUTER_UPSTREAM_* ou ROUTER_BYOK_*. Precedência: dashboard/user-config.json → ambiente → defaults.

02 · escolha

Modelos reais no picker

IDs que não parecem Anthropic ganham um alias só para passar pelo filtro de /model. Antes da chamada, o router restaura o ID original.

gpt-4.1→anthropic-ccb-alias-gpt-4.1→gpt-4.1

03 · trabalhe

Tradução completa na rota OpenAI

Mensagens, imagens base64 suportadas, tools, tool results, JSON, streaming SSE, usage e stop reasons atravessam a ponte nos dois sentidos. Campo incompatível falha alto; nada some em silêncio.

O router nasce desligado. Ativar BYOK ou um fallback pode gerar cobrança no endpoint escolhido. Para OpenAI, informe uma URL de contagem se o seu provedor oferecer essa operação; o protocolo não define um caminho padrão. Credenciais ficam fora do repositório.

Três coisas que o Claude Code nativo não faz

Tudo roda na sua máquina, com o embedding local baixado uma vez na instalação.

Brain KB: memória semântica por projeto

Três camadas locais: storage em SQLite pelo node:sqlite embutido (zero dependência nativa, com fallback para JSON), índice invertido com TF scoring e um grafo de citação de 6 tipos de aresta. Busca vetorial e busca por palavra-chave convivem.

  • Embedding padrão multilíngue (384 dim, 50 idiomas): prompt em PT recupera lição em EN
  • Providers alternativos: Ollama local ou Voyage AI, trocáveis na config
  • Escopo estável por projeto via .claude-boss-project ou CCB_PROJECT_ID
  • Backend opcional MCP Memory HTTP, com wizard, migração e auto-update seguro no início da sessão

Curadoria anti context-bloat

Saídas enormes e buscas recursivas amplas são interceptadas antes de entrarem no contexto. O tom é advisory: os hooks informam e redirecionam, não coagem, e num retry idêntico o comando passa.

  • Comandos curados são bloqueados ou auto-redirecionados para a alternativa enxuta
  • grep -r/rg/find amplos viram consulta estrutural ao grafo quando ele está pronto
  • Guarda de erro: assinatura que já falhou N vezes volta com a causa registrada
  • Whitelist por ecossistema detectada no início da sessão

Aprendizado leve, sem orquestrador próprio

Correções, falhas e padrões reusáveis viram entradas curadas do KB. O self-review lembra o que já deu errado naquele arquivo; a consolidação semanal funde lições quase-duplicadas somando recorrência.

  • Três perfis num eixo só: standard (silencioso, mas aprende), dev e free
  • Troca update-safe pelo comando /boss-profile ou pelo dashboard
  • Retrospectiva de falha e nudge de verificação quando o turno editou arquivo e nada rodou
  • Checklist de revisão recorrente oferecido ao /code-review nativo

E mais quatro peças, ligadas só quando você precisa

Nenhuma delas exige conta, chave ou serviço remoto para o funcionamento padrão.

  • Graph: exploração de repositório

    Sete tools graph_* (hubs por PageRank, busca com vizinhança, quem chama um símbolo) para entender um repo grande sem garimpar arquivo por arquivo. Cliente REST puro do Session Graph Engine: nenhum Java embarcado e, com o daemon offline, falham graciosamente.

  • Dashboard local sob demanda

    Servido em 127.0.0.1, com porta dinâmica e token gerado no boot. A aba Router configura upstream, BYOK, protocolos, URLs e headers; Brain KB, Hooks, Insights e Logs ficam no mesmo painel local.

  • Doctor: diagnóstico zero-config

    Checa Node no PATH e versão, variáveis do plugin, fragmentação de data-dir, modelo de embedding, daemon e token, e quais eventos de hook a sua versão do Claude Code suporta. Vira advisory de uma linha no início da sessão só quando algo crítico falha.

  • BYOK e Model Router (opt-in)

    Nasce desativado. Você conecta custom upstream ou BYOK em Anthropic Messages ou OpenAI Chat Completions, separa as URLs por operação e escolhe modelos não Anthropic no picker por um alias reversível.

Um plugin de memória não pode custar caro para existir

A v2.28.0 consolidou os hooks em seis dispatchers in-process: cada evento lê o payload uma vez e roda seus detectores no mesmo processo, concorrentes e com timeout individual.

EventoProcessos Node
SessionStart12 detectores + o ensure do router13 → 2
UserPromptSubmita cada prompt seu6 → 2
PreToolUse · Bashcuradoria + guarda de erro2 → 1
PostToolUse · Bashdetecção e resolução3 → 1
PostToolUseFailurejournal da falha2 → 1
Stopconsolidado desde a v1.19.011+ → 1
Total eliminadopor sessão, por prompt e por comando≈ 34 spawns
  • Concorrente, não sequencial

    Os detectores de um dispatcher rodam juntos, cada um com o timeout que já tinha. Um laço sequencial trocaria o pior caso por uma soma; a primeira versão fazia isso e foi corrigida antes do release.

  • Timeout genuíno ≠ crash

    Cada resultado é marcado como ok, timeout ou error. Misturar os dois mascararia uma falha real como se fosse lentidão.

  • Auto-update sem interromper seu trabalho

    No SessionStart, o dispatcher existente consulta atualizações no máximo uma vez a cada 24 horas, sem hook novo. Havendo versão, executa check_update → update uma única vez, sem retry e sob lock cross-process, e só conclui quando o restart/reconnect confirma a nova versão em /health.version. Se algo falha, avisa sem bloquear; no fallback do Windows, valida que o PID é Java, promove apenas o JAR baixado e verificado e preserva o anterior para rollback.

  • Nada de regressão silenciosa

    A entrega trouxe 21 testes unitários e 9 de integração real sobre os dispatchers, sobre um gate de 1046 testes unitários. Todos os scripts consolidados mantêm a CLI standalone.

Instalar leva dois comandos

O pré-requisito número um é Node.js 22.13+ no PATH do sistema: o Claude Code dispara hooks e MCP com o node do PATH, não com o Node embutido no Desktop. No Windows, feche o Desktop por completo depois de instalar e reabra, para herdar o PATH.

  1. Adicione o marketplaceUma vez por máquina.
  2. Instale o pluginO postinstall baixa o modelo de embedding (~100–200 MB) para um cache durável, uma vez só.
  3. Use normalmenteA memória indexa sozinha. Opcional: escolha o perfil com /boss-profile.
