01

O que ele faz por você

Motor determinístico + julgamento do agente, sem perder o original.

⚙️

Motor determinístico

A parte mecânica é sempre igual: extrai, prepara, injeta e valida. O agente fica só com o julgamento.

  • 9 tools MCP via daemon HTTP único
  • Fluxo guiado pela skill revisar-rf
  • Sem dependência de "modelo lembrar"
🛡️

Nunca toca no original

A revisão é injetada em colunas anexadas. O arquivo do cliente fica intacto, provado célula a célula.

  • Original 100% preservado
  • Saída versionada _revisado_vN.xlsx
  • Verificação de preservação automática
🧩

Perfis por assunto

Cada tipo de entrega tem suas colunas de análise. Troque o perfil e o motor se adapta.

  • Perfil embutido rf-end
  • Perfis custom registráveis
  • Escopo: .xlsx e .csv
02

O que você ganha

Revisão consistente, auditável e à prova de erro manual.

consistência

Mesma revisão, toda vez.

Porque a parte mecânica é determinística — o que varia é só o julgamento, com o contexto certo.

segurança

O original nunca é perdido.

Célula a célula comparado e versionado. Sem edição manual acidental no arquivo do cliente.

reuso

Memória do projeto vira revisão.

O agente cruza cada requisito com o que o projeto já sabe — regras, decisões e riscos acumulados.

Instale em 2 minutos

Requer Python 3.11+ com openpyxl e um Claude Code que consuma MCP HTTP. O daemon único sobe sozinho no início da sessão — sem um processo Python por sessão.

  1. Adicione o marketplace  AllanSantos-DV/claude-code-plugins
  2. Instale o plugin  um comando, pronto
  3. Peça a revisão de um RF — o fluxo guia o resto
