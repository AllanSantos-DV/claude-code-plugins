O que o plugin faz

Um motor tabular, não um editor manual.

O contrato é claro: o agente julga; o motor executa. As 9 tools do rf-engine preparam, validam, aplicam e provam a preservação para arquivos .xlsx e .csv. Documentos como PDF, DOCX e PPTX ficam fora deste fluxo.

9 tools

Mecânica determinística

rf_prep, rf_apply, rf_validar, rf_status e demais tools cuidam da transformação repetível; nada de editar workbook na mão.

Não-destrutivo

A mesma planilha, versionada

As colunas de análise são anexadas na planilha do cliente. O arquivo revisado recebe sufixo _revisado_vN.xlsx; os dados originais ficam 100% preservados.

Memória

Requisito contra contexto

As tools rf_brain_* cruzam cada RF com a memória do projeto (o seu project_id) antes da conclusão da análise.

Perfis

Colunas por assunto

O mesmo motor troca o perfil de colunas conforme o tema (ex.: rf-end), ou perfis que você registra para outro assunto tabular.

Hooks

O fluxo é lembrado

rf-remind injeta a ordem correta quando a tarefa é RF em planilha; rf-guard redireciona tentativas de gravar XLSX manualmente para rf_apply.

Escopo honesto

XLSX/CSV apenas

Injetar coluna só faz sentido em tabela. Para documentos, use outro fluxo de análise.

Novidade · transporte HTTP

O transporte mudou; as tools não.

O MCP migrou de stdio para Streamable HTTP com um daemon único em 127.0.0.1:19847. As sessões do Claude Code agora conectam como clientes finos via .mcp.json type:http, sem abrir um processo Python por sessão.

  • Um hook SessionStart sobe ou garante o daemon HTTP de forma idempotente.
  • O contrato das 9 tools continua idêntico ao da 0.1.1; só o transporte mudou.
  • Loopback 127.0.0.1, validação de Origin e token opt-in por RF_ENGINE_HTTP_TOKEN.
  • Rollback disponível: /plugin install rf-reviewer@rf-v0.1.1.
−403 MB

Ganho medido: 8 sessões saíram de ~489 MB em 8 processos stdio para ~87 MB em 1 daemon HTTP — cerca de 82% a menos e 7 processos eliminados.

Fluxo de revisão

Ordem explícita, saída verificável.

rf_perfis_listar

Escolha ou confirme o perfil de colunas para o assunto da planilha.

rf_prep

Extraia a tabela e gere o esqueleto de análise.

agente + memória

Preencha a análise cruzando cada requisito com o conhecimento do projeto.

rf_validar → rf_apply

Valide e injete as colunas anexadas na mesma planilha.

rf_verificar_preservacao

Prove célula a célula que o original foi preservado.
